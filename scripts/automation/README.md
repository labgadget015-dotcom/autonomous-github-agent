# Automation Scripts

Auto-generated scripts for common repository tasks.

## Available Scripts

### format-python.sh

Format Python code with black and isort

```bash
./format-python.sh
```

### format-javascript.sh

Format JavaScript/TypeScript code with prettier

```bash
./format-javascript.sh
```

### create-release.sh

Create a new release with automatic versioning

```bash
./create-release.sh
```

### setup-dev-env.sh

Setup development environment

```bash
./setup-dev-env.sh
```

### run-tests.sh

Run all tests with coverage

```bash
./run-tests.sh
```

### lint-code.sh

Run linters on codebase

```bash
./lint-code.sh
```
