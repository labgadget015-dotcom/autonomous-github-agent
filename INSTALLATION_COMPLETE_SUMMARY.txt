================================================================================
  TROUBLESHOOTING
================================================================================

ISSUE: "python: command not found"
SOLUTION:
  - Ensure Python 3.11+ is installed
  - Or use full path: C:\Python311\python.exe RUN_INSTALLATION.py

ISSUE: "pip install fails"
SOLUTION:
  - Try: python -m pip install -e .
  - Or: pip install --user -e .

ISSUE: "ModuleNotFoundError after install"
SOLUTION:
  - Run: pip install -e . --force-reinstall

ISSUE: "autonomous-agent: command not found"
SOLUTION:
  - Run: pip install -e . --force-reinstall --no-cache-dir

For more troubleshooting, see INSTALLATION_INSTRUCTIONS.md
