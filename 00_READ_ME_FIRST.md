→ Ensure Python 3.11+ is installed in PATH
→ Or use: `C:\Python311\python.exe RUN_INSTALLATION.py`

**"pip install fails"**
→ Try: `python -m pip install -e .`
→ Or: `pip install --user -e .`

→ Run: `pip install -e . --force-reinstall`

**"autonomous-agent: command not found"**
