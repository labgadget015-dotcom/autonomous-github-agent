## 🔧 Setup Instructions

### Quick Start (3 steps)

```bash
# 1. Clone repository
git clone <repo-url>
cd autonomous-github-agent

# 2. Run setup
./scripts/setup.sh  # Unix/Linux/macOS
# or
scripts\setup.bat   # Windows

# 3. Verify installation
make validate
```

### Full Pipeline Execution

```bash
# Run complete CI/CD pipeline
make all

# Or individually:
make analyze      # Code analysis
make test-full    # Full test suite
make security     # Security scan
make dashboard    # Generate dashboard
make badges       # Update badges
```

### Start Monitoring

```bash
# Start Prometheus + Grafana
make monitoring

# Access dashboards
# Grafana: http://localhost:3000
# Prometheus: http://localhost:9090
```
